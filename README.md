# 🎯 Event Overview

**BUILD YOUR OWN AI AGENT** is a 4-hour hands-on workshop designed to introduce participants to the fundamentals of AI agents and provide practical experience in building a functional agent from scratch.

Unlike a traditional lecture-based workshop, the event focuses on **learning by building**.

Participants will understand how AI agents are designed, define a specific purpose for their agent, establish its behavior and instructions, connect tools or external resources, test its responses, improve its performance, and finally deploy the completed agent for demonstration.

By the end of the event, every team is expected to have a **functional AI agent that solves a clearly defined problem and can be demonstrated to the organizers and evaluators**.

---

# 🧠 Event Objective

The primary objective of **BUILD YOUR OWN AI AGENT** is to provide participants with practical exposure to the complete AI-agent development workflow.

Participants are expected to:

- Understand the concept and architecture of AI agents.
- Identify a real-world problem that can be addressed using an AI agent.
- Define the purpose and role of their agent.
- Design appropriate system instructions and behavior.
- Configure the agent to perform specific tasks.
- Connect external tools or resources.
- Integrate documents, APIs, web search, calculators, or other approved capabilities.
- Test the agent using different inputs and scenarios.
- Identify incorrect, incomplete, or unexpected responses.
- Improve the agent's instructions, workflow, or tool usage.
- Deploy or publish the completed agent.
- Demonstrate the working agent.
- Explain the problem, design decisions, tools, and implementation.

# 🤖 What Is an AI Agent?

An **AI agent** is a system that uses artificial intelligence to understand a task, make decisions, use available tools or resources, and produce an appropriate result.

A basic AI application may simply respond to a user's prompt.

An AI agent can go further by:

1. Understanding the user's objective.
2. Following defined instructions.
3. Reasoning about the task.
4. Accessing relevant information.
5. Using connected tools.
6. Performing actions.
7. Evaluating or refining its response.
8. Producing a useful final result.

The event introduces participants to these concepts through practical implementation rather than theory alone.

# 🏗️ Agent Building Workflow

Participants will follow a structured development workflow throughout the event.

## Step 1 — Identify the Problem

Teams must identify a meaningful problem that can be solved or assisted by an AI agent.

Possible areas include:

- Student assistance
- Study planning
- Career guidance
- Research assistance
- Coding assistance
- Campus support
- Data analysis
- Productivity
- Customer support
- Information retrieval

---

## Step 2 — Define the Agent

Teams must clearly define:

- Agent name
- Agent purpose
- Target users
- Primary responsibilities
- Expected inputs
- Expected outputs
- Limitations

The agent should have a clearly defined scope rather than attempting to solve every possible problem.

---

## Step 3 — Design Instructions

Teams must define how their agent should behave.

This may include:

- Role
- Personality
- Response format
- Task instructions
- Rules
- Constraints
- Safety boundaries
- Error-handling behavior

Well-designed instructions should help the agent consistently perform its intended task.

---

## Step 4 — Connect Knowledge and Tools

Teams may connect approved external resources to improve their agent's capabilities.

Examples include:

- Documents
- Web search
- APIs
- Calculators
- Databases
- External knowledge sources
- Approved software tools

The tools selected should directly support the agent's purpose.

---

## Step 5 — Build the Agent

Teams will implement their agent using an approved platform, framework, or development environment.

The implementation should include:

- Agent instructions
- Required knowledge
- Tools
- Workflow
- Input handling
- Output handling
- Error handling

---

## Step 6 — Test the Agent

Teams must test their agent using multiple scenarios.

Testing should include:

- Normal user queries
- Unexpected inputs
- Ambiguous queries
- Incorrect information
- Edge cases
- Repeated tasks

Teams should identify weaknesses and improve their implementation accordingly.

---

## Step 7 — Improve

Based on testing results, teams should improve:

- Instructions
- Prompts
- Tool selection
- Workflow
- Knowledge sources
- Response format
- Error handling

The goal is to make the agent more reliable, useful, and consistent.

---

## Step 8 — Deploy

The final agent must be made accessible for demonstration.

Depending on the selected technology, deployment may involve:

- Publishing the agent
- Deploying a web interface
- Providing a shareable link
- Running the agent locally
- Using an approved hosted environment

---

## Step 9 — Demonstrate

Each team must demonstrate its completed agent to the organizers/evaluators.

The demonstration should clearly explain:

1. The problem.
2. The target users.
3. The agent's purpose.
4. How the agent works.
5. Tools or resources used.
6. Testing performed.
7. Improvements made.
8. Final result.
